## Slice 026-06 — Meta custom-data `cd[...]` wire-fidelity fix

**Goal:** Make `connectors/pixel/vendors/meta.js` emit Meta standard-event custom
data under the real `cd[...]` namespace (`cd[value]`, `cd[currency]`,
`cd[content_name]`, `cd[content_category]`) instead of the current **bare** names

confirmed by a real `/tr` capture (`cd[region]=us`) and Meta's docs. Config-only:
no connector-core change.

### Deviation log (after reconciliation)

- **TDD ordering (process, not scope):** the paramMap key rename was applied to `meta.js` before
  the test edits landed, rather than writing failing tests first in strict sequence. Corrected
  retroactively before reporting done: `meta.js`'s `paramMap` keys were temporarily reverted to
  bare (`value`/`currency`/`content_name`/`content_category`) with the updated tests + harness
  left in place, `npx vitest run test/pixel-connector.test.js test/pixel-seam.test.js
  test/parity-meta.test.js` was run and confirmed 10 failures (`test/pixel-connector.test.js` AC2
  table rows + the new AC3 wire-encoding witness; `test/pixel-seam.test.js` AC5; and
  `test/parity-meta.test.js`'s AC2/AC4/AC5/AC6 harness-flip assertions, 5 failures) reproducing
  exactly the pre-fix bare-name behavior, then the `cd[...]` keys were restored and the same run
  went green (98/98 across the six affected files). This satisfies the DoD's "each new/changed
  test shown to red when the keys revert to bare" without changing any AC or scope.
- **Harness flip mechanism — full removal, not `gap-closed`:** `rig/parity/oracle.js`'s `diffParity`
  offers two ways to land a formerly-gapped field: leave the `gapMap` entry (bucket becomes
  `gap-closed`, still green but still gap-map-annotated) or remove it (bucket becomes a plain
  `maps`). AC2's wording ("records a real MATCH … matched, not gapped") reads as the latter, so the
  four `cd[...]` entries were REMOVED from `rig/parity/descriptors/meta.js`'s `gapMap` entirely
  (not left in place with a `gap-closed`/"owner landed" flag) — confirmed via `npm run parity:meta`
  (`counts.maps: 6`, `counts.expected-dropped: 4` — down from 8 — no `gap-closed` bucket present).
- **Extra test coverage beyond a 1:1 rename:** `test/pixel-connector.test.js`'s AC2 table gained a
  blanket "the pre-fix bare names never appear as a query key" assertion on every row (not just the
  rows that previously listed them in `absentParams`), plus one new dedicated test asserting the
  literal wire-encoded substrings `cd%5Bvalue%5D=25` / `cd%5Bcurrency%5D=USD` on the RAW
  (undecoded) `req.url` string — `URL#searchParams` alone would only prove the semantic key name,
  not the actual on-the-wire percent-encoding AC3 calls out. Additive, not a scope change.
- No ADR, `docs/architecture.md`, or `docs/decisions/*` edit was needed (config + harness + test
  fix only, no module-boundary or connector-core change) — confirmed by inspection, not asserted by
  a new automated guard (the existing `git diff -- connectors/pixel/connector.js` /
  no-vendor-string-grep canaries in `test/pixel-vendors.test.js` / `test/pixel-config-contract.test.js`
