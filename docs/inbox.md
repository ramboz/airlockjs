- [2026-09-03] **Inspector collector's buffer isolation is SHALLOW — relies on the flat-record invariant** (spec 028-01, `core/inspector/collector.js`). The collector shallow-copies each 009-02 record on write + on query, which fully isolates the buffer **because every enforcement record is currently FLAT** (all values are string|number — enumerated across the three hosts in the 028-01 craft review). If a future emit site ever adds a **nested object/array** value to a record, that reference would be shared across the buffer and every query result, and the AC2 copy test (which mutates only top-level keys) would not catch it. Documented as a deliberate invariant in `collector.js`; the trigger for a deep-copy/freeze-on-write is "a nested-value record is introduced." Not a current bug (no such record exists) — flagged so a future nested-record emit site upgrades the copy.
